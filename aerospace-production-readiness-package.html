What Belongs in a Production-Readiness Package for First Article

First article fails for missing dimensions. It also fails because the process that made the part cannot be shown on paper.

Readiness is a set, not a checklist item

Before a first-article aerospace part should run, the manufacturer needs a description of the process as it will run, an analysis of where that process can produce nonconforming product, the controls that will be used anyway, and a way to record the results. Those are separate documents. They have to describe the same process.

Minimum package

  • Process Flow Diagram — operations, inspection points, rework loops, outside processing.
  • PFMEA — written against that flow, not against a generic machining template.
  • Control Plan — methods, frequencies and reactions that match the risks and the drawing.
  • Inspection plan — including the FAIR / layout characteristics that will be reported.
  • Work instructions for the operations that can actually be done wrong.
  • Reaction plans that a supervisor can follow without inventing them at 6 p.m.

Ballooned drawing, traveler, and fixture or program list sit next to this set. They are inputs. They are not a substitute for the quality documents.

What “ready” looks like in a review

Someone who did not write the package can pick a key characteristic and walk it through every document without a conference call. Revision letters match. Outside processes appear in the flow. Special characteristics are classified the same way on the drawing and the Control Plan. The inspection record has a place for the result you promised to take.

If that walk fails in the conference room, it will fail at source inspection.

Low-volume is not an excuse for a blank PFMEA

Space and defense hardware often run in very small lots. The risk is higher, not lower. The PFMEA should be specific to the build, not padded with generic “operator error” rows. Detection that only exists at final inspection needs to be honest about that, and the Control Plan should not pretend an in-process check is happening if it is not.
